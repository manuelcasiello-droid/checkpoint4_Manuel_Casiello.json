# Preentrega 4: Sincronización del Cerebro Agéntico con Ecosistemas de Negocio

## Descripción del Proyecto
Ecosistema de e-commerce automatizado diseñado en n8n que conecta un sistema multi-agente con herramientas externas reales, incorporando controles preventivos no-code (filtro anti-bucle, memoria persistente, control de duplicados y seguridad Human-in-the-Loop).

## Stack Tecnológico Utilizado
- **n8n:** Orquestador de flujos de trabajo.
- **OpenAI (GPT-4o-mini):** Cerebro agéntico para clasificación y redacción.
- **Airtable:** Memoria persistente y control de sesiones.
- **HubSpot:** CRM para sincronización y prevención de duplicados (Error 409).
- **Gmail:** Casilla de soporte (Trigger) y generación de borradores (HITL).
- **Slack:** Canal de operaciones y alertas para el equipo.
